# 墨页 · Moye Browser

墨页是一款以阅读空间和底部单手操作为中心的 Android 浏览器。无需注册，没有资讯流、广告 SDK 或统计 SDK。

- [官网与下载](https://lcstp.com/projects/moye)
- [最新安装包](https://github.com/LingCore/MoyeBrowser-Downloads/releases/latest)
- 支持 Android 9 及以上；一个 APK 包含 ARM64、ARMv7、x86 和 x86_64。
- 在墨页「设置 → 软件更新」中检查、下载并通过 Android 系统安装更新。

本仓库用于发布安装包、文件校验值和版本说明。请从官网或本仓库下载，并核对发布页提供的 SHA-256。更新时保留已有书签与设置，不需要卸载旧版本。

第三方组件的来源与完整许可可在应用「设置 → 开源许可」中查看；各组件保留自己的版权与许可。

The official binary download repository for Moye Browser. Android 9 or later is required. Check for updates in Settings; Android asks you to confirm installation. Third-party licenses and attribution are included in the app.
